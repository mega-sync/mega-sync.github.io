The Mega desktop app download is on Mega's official site for Windows 10 or later, macOS 10.15 or later and Linux. The current release is 6.7.0.3, tagged on 26 October 2026. It works with a free 20 GB account, and paid plans add storage.

This is an independent guide, not Mega's website. Buttons lead to the official Mega site and may be affiliate links; if they are, the price you pay does not change. Facts were checked on 6 November 2026 against Mega's public GitHub repositories and its App Store listing.

What you get

The Mega desktop app download gives you the official client that links folders on your computer to your Mega cloud drive. There is no separate app licence in the sources read for this page: the source code is public on GitHub, and what Mega sells is storage.

  • Two way sync: changes made on the computer or in the cloud are applied to the other side
  • A Backups tab next to the Syncs tab in the Settings dialog
  • A File Manager for the cloud drive, reworked in version 6.5.0
  • Screenshot capture, annotation and sharing, added in version 6.7.0.3

Trial and licence terms

There is no time limited trial to start. Mega's listing describes the free plan as 20 GB of encrypted storage with no credit card, and says you can upgrade at any time. Paid plan names, the storage stated for them and the renewal rules are on the pricing page.

Refund terms are not stated in the sources read for this handbook. Check the terms on Mega's site before paying for a plan.

If you would rather script uploads and scheduled backups than use a window, Mega also publishes a terminal client. The MEGAcmd backup guide covers it.

Install in four steps

  1. Open the official download pageUse the button on this page. It leads to Mega's desktop page, which offers the build for Windows, macOS or Linux. Do not use mirror sites or repacked installers.
  2. Choose your systemOn Linux, pick your distribution. Mega officially supports Debian, Ubuntu, Mint, Fedora and CentOS and lists prebuilt packages for other distributions on the same page.
  3. Run the installer and sign inSign in with your Mega account or create a free one, which includes 20 GB. Store your account recovery key somewhere safe; Mega presents it as the thing that keeps access to your data in your hands only.
  4. Add a sync or a backupOpen the Settings dialog and use the Syncs tab to pair a local folder with a cloud folder, or the Backups tab to back a folder up. Remember that a sync is two way and mirrors deletions.

Frequently asked questions

Is the Mega desktop app free to download?

The sources read for this page show no purchase price for the app itself. Mega sells storage plans, and the free plan includes 20 GB with no credit card.

Which version will I get?

The current release is 6.7.0.3, tagged on 26 October 2026 for Windows, macOS and Linux. Mega's download page serves the current build for the system you choose.

How big is the Mega installer?

Mega does not state the installer size in its README or release notes, so this page does not quote one. Your browser shows the size when the download starts.

Does the Mega desktop app run on Windows 7 or 8?

No. Mega's README sets Windows 10 as the minimum for the desktop app, and Windows Server 2019 for server systems.

Where should I download Mega from?

Only from Mega's official site, which is where the buttons on this page lead. This handbook does not host installers and does not link to other download sites.
